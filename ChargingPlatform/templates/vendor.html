Test checklist

Commands

Sent to this charger only

Charging

Sends RemoteStartTransaction or RemoteStopTransaction. Plug the cable in first. Stop ends whatever transaction is running on this charger.

Firmware update

Sends UpdateFirmware with this download address and "now" as the retrieve date. The charger must be able to reach the address itself.

Trigger a message

Asks the charger to send a message now (TriggerMessage).

Configuration

GetConfiguration reads every key, or one if you name it. ChangeConfiguration needs a key and a value.

Reset and unlock

A hard reset interrupts a running transaction.
